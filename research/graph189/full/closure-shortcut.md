# Obstruction to the complete ordinary path-closure shortcut

For every integer t≥3 take a cycle of seven blocks of t vertices. Turn each block into a clique and make consecutive blocks completely adjacent, with no edges between any other blocks. Each vertex has degree 3t−1 and exactly 2t vertices at distance two. The graph has diameter three and order 7t. Thus it satisfies the even-distance bound, contains triangles, and has minimum degree at least three. For the remaining H2 inequalities, 6t−1<7t≤(3t)² and 7t>2(3t−1)+3. A Hamilton cycle is obtained by visiting each block consecutively. Its cyclic successor maps any independent set injectively into its neighborhood.

Every nonedge has degree sum 6t−2<7t−1, so the ordinary path closure adds no edge. The stronger distance-three closure steps of Easwar–Johari with thresholds n−2 and n−3 likewise add no edge for t≥3. This is an infinite family meeting all the H2 premises on which complete ordinary closure is unavailable.
