# Independent audit of the original-core argument

Audited split/three-port-first-order.md, SHA-256 1bbeaef6fb6e472fde7ed4d8d5348fd6aea09a0066f74c29810116683607dbd3. The asserted theorem holds for every k≥7 at exactly h=2k−2, including U empty.

The elementary extremal lemma is correct. For a longest nonspanning path of t vertices in a connected graph, closing its vertices into a cycle would extend the path. The two standard endpoint-neighbor index sets in {1,...,t−1} must therefore be disjoint, giving t−1≥2m. At n=2m+2 there is one omitted vertex. Its m neighbors form an independent set in the path on positions 2,...,2m of size m, necessarily the even positions. Replacing any odd-indexed vertex by the omitted vertex leaves the even positions fixed, including for the two path ends, proving the claimed independent join.

The port and exceptional-join contradictions count genuine distance-two vertices. When an anchor is complete to all other anchors and misses a port, the missed port has another incident anchor. Core vertices having all three port neighbors see every core nonneighbor through a port and at least two anchors. An independent-side vertex in the exceptional join sees the k−1 others at distance two through every one of the k−2 opposite vertices. All its ≥2 ports therefore have one common singleton anchor. The collective anchor union has size ≥2, so among three ports there is at most one such pair. One port would then cover all k independent vertices, exceeding k−1.

The endpoint rotation counts the original Hamilton path for the predecessor i=h−1 and different endpoints for every other neighbor. The rotated endpoints avoid the fixed starting vertex. If all fail distinct assignment, each belongs to the same S_p as the fixed vertex; this gives k contacts. Distinct endpoint ports allow shell insertion since the remaining port cannot form two bad anchor pairs. This rotation/gluing implication holds for ANY h>k, contingent on traceability of the original R, since a single-port endpoint has core degree ≥k−1 independently of h and each port has ≤k−1 core neighbors.

In the disconnected case, the degree bound and h=2k−2 force two cliques of k−1. Distinct port pairs give the stated traversal. If both cliques have only the same pair, a t contact can be combined with one of the two different contacts witnessing the existing pair. Thus t misses both and connectedness of D supplies its port edge. Either route permits an anchor-ended spanning shell path to be prepended.

Scope: the order equation n=k+6+h imposes h≥2k−3, not h≤2k−2. The three contact sets cover R but individually only give h≤3k−3. The result together with the old h=2k−3 case leaves h≥2k−1. A separate argument is required to exclude or handle those orders. No assertion about their feasibility is necessary for this scope limit.
