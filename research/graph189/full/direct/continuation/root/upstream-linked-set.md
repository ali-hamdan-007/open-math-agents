# The upstream linked-set theorem needed for Graph 189

An upstream proof by **@koolkao** establishes Ma, Ning and Zhao’s explicit large-order theorem for longest cycles. Its accepted source also contains the more useful theorem `OMA.BondyK.linked_contra`. That theorem applies at every graph order when one can exhibit a linked set outside a longest cycle. This removes the need to formalize a classical cycle theorem from scratch in this approach. For a finite λ-connected graph K, let C be a longest cycle and let M be a set of at least λ+1 vertices in one component of K−C. Assume that for any distinct ordered endpoints in M there is a simple path within M between them containing at least λ vertices. Upstream’s linked-set theorem contradicts
`|V(K)| + λ(λ−1) ≤ (λ+1)δ(K)`. For λ≥1 and δ(K)≥λ this gives
`(λ+1)(δ(K)−λ+2)−1 ≤ |V(K)|`.
This is precisely the form of the order bound consumed by the Graph 189 structural reduction. There is no lower bound on |V(K)| in this internal theorem. The top-level explicit theorem has the additional threshold 5λ²+7λ.

`Graph189LinkedExterior.lean` defines this linked-set condition using actual mathlib walks in the exterior graph and supplies its kernel-checked injective transport. `extract_bondy_core.py` reproduces a focused copy from the accepted Git blob and the pinned formal-conjectures checkout, preserving upstream’s proof text. The application requires both the conversion of native linked sets to upstream’s internal representation and actual linked sets in the relevant universal completions at λ=κ or κ+1. Separate paper and Lean work address those obligations. Neither the size of a finite test nor the official Bondy verdict supplies these Graph 189 witnesses.

In the alternative where deleting a minimum-degree vertex leaves a Hamiltonian path, `Graph189RootedSplice.two_tight_gaps` is kernel-checked. It proves two distinct gaps have minimum length when the total excess over the minimum is at most the number of marks minus one. The combinatorial conversion of these gaps into actual distance-two witnesses is described in [the rooted proof](../lowblock/rooted-singleton-kernel.md). `lowblock/Graph189SmallMinimumOrder.lean` separately checks an order lower bound (δ+1)(⌊k/2⌋+2) in the minimum-deletion case under its graph and cap hypotheses.
