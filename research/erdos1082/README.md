# Two three-distance base exclusions for Erdős 1082

The exact target is `Erdos1082.erdos_1082.parts.i.R1.H2.R1.H4.R1.H2.R1.H3.R1.H2`, reduction #5040. The two five-point base codes are 123 and 157. The argument below excludes a ten-point extension in each case.

## Normalization

Write 0, 1, 2, 3, 4 for the five base points. Both codes give the same length from point 0 to each peripheral point, and the segment from point 1 to point 2 has that length. Translate point 0 to the origin and scale that length to 1. An orthogonal change of coordinates puts points 1 and 2 at $(\sqrt3/2,-1/2)$ and $(\sqrt3/2,1/2)$.

For code 123, points 1 and 2 are equidistant from point 3, so point 3 lies on the horizontal axis. Its coordinates are $(\varepsilon,0)$ for $\varepsilon\in\{-1,1\}$. Points 3 and 4 lie on the unit circle and are equidistant from point 1. The line obtained by subtracting the squared-distance equations intersects the unit circle in at most two points. Reflection across the line through the origin and point 1 fixes those equations and sends point 3 to $(\varepsilon/2,-\varepsilon\sqrt3/2)$. Distinctness forces this to be point 4.

For code 157, the distances from point 3 to points 1 and 2 are the distances from point 4 to points 2 and 1, respectively. Since points 1 and 2 are linearly independent, the unit radius and these two squared distances uniquely determine the coordinates. Therefore points 3 and 4 are $(x,y)$ and $(x,-y)$. Equality of the distances 1–3 and 3–4 gives $\sqrt3 x=2+y-4y^2$. Using $x^2+y^2=1$ gives $(2y-1)(8y^3-6y-1)=0$. If $2y=1$, then point 3 is point 2, contrary to distinctness. The three remaining roots are exactly $\sin(-10°), \sin(-130°), \sin(-250°)$. They satisfy the cubic by the triple-angle formula and are distinct. Thus the enumeration uses all possible base forms for these codes.

## Exact extension calculation

In each form, let $d_0,d_1,d_2$ be the three squared base distances and let $T=M^2$ be the fourth squared distance. The target requires $T$ distinct from the three base values. For any additional point $P=(a,b)$, assign one of $d_0,d_1,d_2,T$ to each of its five squared distances from the base. This gives $4^5$ assignments. Subtract the squared-distance equation at the origin from the equation at each of the four unit-radius peripheral points. For a peripheral point $(p,q)$ with assigned squared distance $D_i$ and origin assignment $D_0$, the resulting equation is
$pa+qb=(1+D_0-D_i)/2$.

The equations for the first two peripheral points are independent and express $a,b$ as affine functions of $T$. The other two equations either give incompatible values, force a unique $T$, or are identities. For every surviving assignment with a forced $T$, substitute it into the origin equation, discard existing base points, and add the resulting point to its bucket for that exact $T$. Assignments with both equations identities never involve $T$ in any of the five forms. These give a separate list of points available for any $T$.

All arithmetic runs in the exact number field generated by $t=2\cos(10°)$, using its polynomial $(t^3-3t)^2-3$. This polynomial is irreducible by Eisenstein at 3, and its largest real root is $t$. The cosine recurrence evaluates the base coordinates in this field. Run `python exact.py` with SymPy installed.

A ten-point extension would require five additional points at the same fourth distance. Each form allows at most four. The calculation permits collinearity and fourth distances below the base maximum, so the upper bound also applies with the target's stronger hypotheses.
